# Guildrun audio assets

Generated by [`scripts/agent_audio_convert.py`](../../../scripts/agent_audio_convert.py) from the demo's FMOD banks
(`Guildrun_Data/StreamingAssets/{MUSIC,SFX,VO,MASTER}.bank`).

## Pipeline
1. **vgmstream-cli** (auto-downloaded to `%LOCALAPPDATA%/guildrun_tools/vgmstream` if not on PATH) decodes every FSB5
   subsong. FSB5 Vorbis stores headerless Vorbis packets whose setup header is referenced by CRC32 (chunk type 11);
   vgmstream ships the FMOD setup-header table and rebuilds a valid decoder state. `-i` ignores loop points.
2. **ffmpeg / libvorbis** re-encodes to Ogg Vorbis (music q4, sfx/vo q3), 48 kHz stereo.
3. `manifest.json` is written.

Result: 610 files, ~24 MB (`music/` 11, `sfx/` 276, `vo/` 323 incl. Dragomir's lines from MASTER.bank).

## manifest.json
```jsonc
{ "base": "/assets/audio/",
  "logical": { "music.menu": ["music/mus_mainmenu_86bpm_premaster.ogg"], "sfx.hit": [ ...variants ], ... },
  "files":   { "sfx/ui_shop_reroll_click": { "file", "name" (original FSB5 name), "bank", "subsong" } } }
```
Logical names: `music.{menu,combat,calm,boss,boss_pre,shop,win,lose,sting.*}`, `amb.{menu,forest,portal}`,
`ui.{click,menu_click,hover,start,reroll,equip,unequip,buy,buy_relic,sell,freeze,unfreeze,fight,hero_pick,hero_drop,
hero_select,rankup,...}`, `sfx.{hit,attack,ranged,cast,death,boss_roar}`, `comic.0{1,2,3}`,
`hero.<id>.{attack,hit,skill,skill_hit}` (heroes + enemies), `vo.<id>.{attack,buy,death,rankup,special,line}`.

Internal VO name aliases: rowan→rook, zuri→selkhera, pollen→floeria, rip→cenk, nyx→nyxa, seraphim→seraphael,
grace→josephina, **zaya→javryn (guess)**. VO code meaning (OP=buy/start, OD=death, OR=rank-up, OSR=special,
AA=attack grunt, DISC=situational) is inferred from naming, not from FMOD event graphs.
Generic `sfx.*` groups are hand-picked approximations (FMOD event→sample graphs were not parsed).
