## APPROX decisions

- board.playerRows = [0, 1, 2, 3]: inferred from enemy placements (all enemies on rows 4..7 across 255 stages/fight-modes). Width/height 7x8 are real data.
- Hex grid orientation/offset parity (odd/even rows) is not serialized in balancing data; renderer must choose.
- hero.price = HeroSheet PriceRange.x (all heroes: [(25, 25)]). ShopSingleton.heroRankCosts {'1': 15, '2': 25, '3': 35, '4': 45} is exported in shopPrices.heroRank — the shop very likely charges by rolled rank (rank-1 cost 15 == StartingShards 15); RUN agent should prefer heroRankCosts for shop slots.
- item.price / relic.price = ShopSingleton.itemRarityCosts / relicRarityCosts by Rarity; rarities without a cost entry (relic Unique/SingleBattleBoost/Enemy/ActBoss) get price null (not sold in shop).
- stage.background/backgroundLayers: 3D environment scenes mapped to extracted 2D RuinsForest layers by time-of-day suffix (Morning/Evening/Dusk); Boss stages use RuinsForest_BossStage_* layers.
